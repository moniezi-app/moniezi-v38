# MONIEZI v38.0.17 — Dark Blue Visual System

## What changed

- Introduces a dark-mode blue visual system based on the Overview Net Profit card.
- Standard dark cards now use blue/indigo panel surfaces instead of generic slate.
- Nested boxes, metrics strips, and secondary cards use darker inset blue surfaces.
- Card borders/dividers now use blue-tinted separators for better delineation.
- The app chrome (header, footer nav, overall shell) remains near-black to preserve contrast.
- Input fields and dense controls remain darker than their surrounding panels to keep forms easy to read.
