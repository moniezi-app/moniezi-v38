# MONIEZI v38.0.23 — App Installation & Demo Language Refinement

## Installation experience

- Changes the installation gate headline to “Install MONIEZI.”
- Uses one concise instruction: “Add MONIEZI to your Home screen and use it like a regular app.”
- Removes the browser-use alternative and the browser-record warning from the primary installation screen.
- Simplifies the installation-complete state to “MONIEZI is installed” and “Open MONIEZI from your Home screen to get started.”
- Removes the previous browser/storage explanation from the completion state.

## Demo experience

- Changes the active banner from “Demo data” to “Demo mode.”
- Uses the concise line “You’re viewing sample business data.”
- Changes the banner action from “Remove” to “Exit Demo.”
- Replaces two simultaneous demo-load confirmations with one: “Demo ready. Sample business data is loaded.”
- Keeps Demo access permanently available in both Menu and Settings.
- Keeps safe preservation/restoration of the customer’s own business when entering or exiting Demo Mode.

## Compatibility

No business-data fields or storage keys were changed. Existing v38 records, backups, demo data, jobs, reports, receipts, invoices, estimates, mileage, and settings remain compatible.
