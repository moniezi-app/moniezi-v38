# MONIEZI v38.0.27 — Clean Add Selector & Icons

This release refines the unified Add experience introduced in v38.0.26.

- Removes redundant “New entry” and technical keyboard-flow language.
- Shows “What are you adding?” only before a type is selected.
- Removes the redundant explanatory empty-state panel.
- Adds a visual icon to every Add selector option and to the selected value.
- Preserves the existing unified Add routing and all underlying forms.
