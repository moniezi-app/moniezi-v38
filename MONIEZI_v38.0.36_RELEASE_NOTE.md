# MONIEZI v38.0.36 — Welcome & License Activation Cleanup

This release simplifies the first-run license gate so a buyer sees one clear activation path rather than repeated instructions.

- Keeps the MONIEZI welcome/logo area and purchase-positioning line.
- Uses “Activate MONIEZI” as the activation-card heading and primary action.
- Uses “Paste or enter your license key” in the key field.
- Shows one small helper line pointing to the purchase confirmation.
- Removes “Enter your license key to unlock MONIEZI,” “Need a license?”, the secondary purchase-confirmation block, and the Track Income / Manage Expenses / Create Invoices preview cards.
- Leaves license verification and all existing application data/workflows unchanged.
