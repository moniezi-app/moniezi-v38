# MONIEZI v38.0.19 — Job Dashboard & Quick Add Integration

## Job workflow

- New Job / Project is now available directly from Quick Add.
- Job list cards open a Job Dashboard rather than the metadata editor.
- Job Dashboard shows Invoiced, Collected, Outstanding, Expenses, Estimated Job Profit, margin, Cash Position, quoted estimate value, and mileage.
- Invoice, Estimate, Expense, and Mileage can be created from inside a job and are automatically linked to it.
- Job Activity combines linked invoices, estimates, direct income, expenses, and mileage in chronological order while suppressing duplicated invoice-payment transaction rows.
- Edit Job Details remains available as a secondary action.

## Compatibility

No migration is required. The Job/Project data model is unchanged; v38.0.19 is a workflow and presentation upgrade on top of v38.0.18.
