# MONIEZI v38.0.33 — Unified Specialized Add

This release finishes the shared Add experience across all seven creation types.

## Changes

- Added clear section containers around Money & Sales and Business in the full-screen Add picker.
- Added the shared icon-led Add selector to new Mileage, Client, and Job / Project forms.
- Preserved specialized fields and save behavior for Mileage, Client, and Job / Project.
- Kept edit forms focused: existing records do not expose the creation-type selector.
- Version and service-worker cache advanced to 38.0.33.
