# MONIEZI v38.0.26 — Unified Add Selector

This release removes the duplicate Quick Add tile popup and standardizes record creation around one shared Add flow.

Home `+` and Activity `+` now use the same Add drawer. Activity keeps its context: Income, Expense, and Invoice open their matching form immediately. Home and Activity All start with the shared selector.

The selector provides Income, Expense, Invoice, Estimate, Mileage, Client, and Job / Project, grouped into Money & Sales and Business. Specialized records hand off to their existing focused editor so no form functionality is lost.
