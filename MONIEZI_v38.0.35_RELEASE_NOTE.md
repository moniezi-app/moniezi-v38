# MONIEZI v38.0.35 — Complete Hamburger Menu Directory

The hamburger menu is now a complete navigation directory instead of a selective list of occasional destinations.

- Settings moved to the top.
- Added Home, Activity, Reports, Invoices, Mileage, Receipts, and Tax Prep / Readiness.
- Grouped destinations into Main, Your Business, Records & Tax, Trying MONIEZI, Advanced, and Support.
- Bottom navigation remains unchanged as the fast-access layer.
- Receipts and Tax Prep shortcuts route directly to the relevant existing views.
