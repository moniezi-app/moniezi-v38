# MONIEZI v38.0.29 — Direct Add Picker & Font Consistency

## Changes

- Removes the intermediate Add illustration/selector screen.
- Home and Activity “+” with no preselected record type now show the seven Add choices immediately.
- Keeps direct contextual creation for Activity Income, Expense, and Invoice.
- Uses larger, one-tap rows and icons for Income, Expense, Invoice, Estimate, Mileage, Client, and Job / Project.
- Preserves the Money & Sales and Business grouping without an inner scrolling panel.
- Corrects the runtime MONIEZI font stack from the stale Inter fallback to the bundled Plus Jakarta Sans Variable font.
- Ensures the screen-style MONIEZI selector explicitly uses the app font and reduces excessive heading tracking.
- No demo, transaction, storage, report, receipt, licensing, or job-costing logic was changed.
