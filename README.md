# MONIEZI v38.0.31

Source package for the v38.0.31 Add Picker Refinement & Version Sync release.

## New in v38.0.31

- Removes the redundant “Choose an item” heading from the Add picker.
- Keeps Add choices at Plus Jakarta Sans weight 400 while giving “Money & Sales” and “Business” section labels weight 500.
- Refines Add choice icons to a lighter 1.25px stroke.
- Synchronizes the customer-facing app version with `package.json` at build time so Settings, Menu, reports, backups, and other runtime version displays stay aligned.
- Advances the PWA service-worker cache for the new release.

MONIEZI v38.0.31 preserves the v38 data model and remains compatible with existing v38 backups and installed PWAs.
