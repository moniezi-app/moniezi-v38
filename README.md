# MONIEZI Pro Finance v38.0.12

Release date: 2026-08-10

## What changed

- Estimates now use clearly separated individual cards instead of one continuous divided list container.
- Invoice cards and estimate cards now use stronger, more visible borders so each record is easy to distinguish.
- Activity search on mobile now hides the fixed bottom navigation while the search field is focused, preventing the navigation bar from covering the search area when the on-screen keyboard opens.

## Notes

Business logic, storage, licensing, PDFs, calculations, exports, and the broader v38 behavior remain unchanged. This release is focused on invoice/estimate card clarity and the Activity search keyboard overlap fix.
