# MONIEZI v38.0.16

Source package for the v38.0.16 Commercial Readiness & Demo Synchronization release.

## New in v38.0.16

- Rebuilt the existing demo as one deterministic, authoritative business dataset so first-run counts, screenshots, reports, and demonstrations stay consistent.
- Demo now showcases Jobs / Projects, Job Profitability, Monthly Goals, Continue Work, Tax Prep Readiness, receipts, mileage, invoices, estimates, and follow-ups as one connected business story.
- Home hierarchy was consolidated: Needs Your Attention handles urgency, Continue Work handles productivity, and invoice/pipeline sections avoid repeating the same alerts.
- Customer-facing product identity is standardized as MONIEZI across the app, installed PWA metadata, and generated reports.
- Removed stale cross-product wording from customer-facing advanced-area copy.
- Added regression coverage for deterministic demo data, record links, receipt coverage, tax-readiness examples, goals, and the headline job-profitability scenario.

## Compatibility

v38.0.16 preserves the v38.0.15 data model and all earlier MONIEZI records. Existing installed v38 PWAs keep the same manifest application ID so updates continue normally.
